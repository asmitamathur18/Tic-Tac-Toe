Tic Tac Toe
A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.
You can play either against the computer or with another person on the same device.
Made as a small frontend project to practice game logic and DOM manipulation using vanilla JS.

Features
Two game modes:
Player vs Computer
Player vs Player
Player X always starts
Computer plays automatically in vs Computer mode
Restart button to reset the game
Clean, minimal UI
No external libraries or frameworks

Live Site
Play it here:
👉 https://asmitamathur18.github.io/Tic-Tac-Toe/

How the Game Works
The board is stored as an array of 9 cells
Clicking a cell updates the board and UI
Win conditions are checked after every move
In computer mode, the computer selects a random available cell

Why I Made This
I wanted to build a small game using only vanilla JavaScript and get more comfortable with handling state, events, and DOM updates.
